##¿Qué es SQL?

SQL es un lenguaje utilizado para gestionar y consultar bases de datos relacionales.

SQLite es un sistema de bases de datos ligero que permite almacenar información en un único archivo.

En este proyecto utilizamos SQLite durante el proceso de construcción de la web para indexar los artículos y generar archivos JSON.


##Ventajas de SQLite

- Es ligero y sencillo de utilizar.
- No necesita un servidor independiente.
- Permite realizar consultas SQL.
- Es ideal para proyectos pequeños y medianos.
